# Отчёт по оплатам договоров

Небольшой Python CLI: читает договоры, работы и платежи из CSV, проверяет входные данные и строит отчёт на указанную дату. Внешние библиотеки не нужны, денежные значения рассчитываются через `Decimal`.

## Быстрый запуск

Требуется Python 3.10 или новее. Из корня проекта выполните:

```powershell
py -3 report.py --date 2026-11-10 --data-dir data --output-dir report
```

В Linux и macOS используйте `python3` вместо `py -3`.

Результат появится в двух файлах:

- `report/works.csv` — цена, выплаченная сумма и остаток по каждой работе;
- `report/contracts.csv` — итоги и сверка по договорам.

Запуск всех автоматических тестов:

```powershell
py -3 -m unittest discover -s tests -p "test_*.py" -v
```

Подробности принятых допущений находятся в [`DECISIONS.md`](DECISIONS.md), результаты расширенной проверки — в [`TEST_REPORT.md`](TEST_REPORT.md), записка бухгалтеру — в [`ACCOUNTANT_NOTE.md`](ACCOUNTANT_NOTE.md).

# Исходное тестовое задание: аванс по договору

Около 2-3 часов. Работа - в Claude Code.

## Контекст

Компания заказывает работы у подрядчиков: съёмки, дизайн. Договор с подрядчиком - это общая сумма на несколько работ. Платим по договору авансом и остатками, иногда платёж привязан к конкретной работе.

Письмо бухгалтера:

> Мне нужен отчёт: по каждой работе - сколько уже выплачено и сколько осталось оплатить, и итог по каждому договору. Сейчас считаю в таблице руками и путаюсь: платежи по договору ни к какой работе не привязаны, а мне надо понимать, за что мы уже рассчитались. Отчёт нужен на дату, для проверки - на 10.11.2026.

## Что есть

Папка `data/`: договоры, работы, платежи и описание формата в `FORMAT.md`.

Бухгалтер в отпуске и на связи не будет, других источников, кроме `data/`, нет. Где данных не хватает, решите сами и запишите допущение в `DECISIONS.md`.

## Что сдать

1. **Программа** на Python или TypeScript - скрипт, CLI или маленький HTTP-сервис, на ваш выбор. По файлам из `data/` и дате она строит отчёт:
   - по каждой работе: цена, выплачено, осталось оплатить;
   - по каждому договору: итоги.

   Напишите, как её запустить: мы запустим сами.

2. **Файл `DECISIONS.md`** - решения, которые вы приняли по ходу работы. По каждому решению коротко:
   - что решали;
   - какие были варианты;
   - что выбрали и почему;
   - что изменится в отчёте, если выбор окажется неверным.

   Пример оформления на постороннюю тему:

   > **Формат отчёта.** Варианты: таблица в консоли или файл CSV. Выбрал CSV: его можно открыть в таблице. Если неверно, поменяется только вывод, расчёт останется прежним.

3. **Записка бухгалтеру** на 5-10 строк простым языком: как читать отчёт и что ей нужно подтвердить, когда вернётся.

4. **Полный транскрипт работы с Claude Code** - экспорт командой `/export`, без правок. Если сессий было несколько - все. Ключи и пароли, если попали в сессию, можно вырезать.

Интерфейс, база данных и docker не нужны. Деньги считайте точно, до копейки, без float.

Не успели всё - напишите, что осталось и что бы вы сделали дальше.

## Подробности решения

### Требования

- Python 3.10 или новее;
- внешние библиотеки не требуются.

### Запуск

Из корня проекта:

```powershell
py -3 report.py --date 2026-11-10 --data-dir data --output-dir report
```

В Linux и macOS вместо `py -3` обычно используется `python3`.

Программа сначала полностью проверяет входные файлы. При ошибке она выводит понятное сообщение в stderr, ничего не записывает и завершается с кодом 2. При успехе в каталоге `report` создаются:

- `works.csv` — цена, фактическая и расчётно распределённая оплата, остаток по каждой работе;
- `contracts.csv` — итоги и сверка по каждому договору.

CSV записываются в UTF-8 с BOM, поэтому русские буквы корректно открываются в Excel. Существующие одноимённые файлы отчёта перезаписываются.

### Тесты

```powershell
py -3 -m unittest discover -s tests -v
```

Тесты проверяют приоритет прямого платежа, распределение общего аванса, границы дат оплаты и возврата, будущие платежи и завершения, отменённые работы, ссылки между CSV и точность денежных значений.

Расширенный изолированный прогон на случайных данных:

```powershell
py -3 tests/system_randomized.py --cases 250 --seed 20261116
```

Генератор использует только системный временный каталог и не меняет `data/` или штатный `report/`. Подробные результаты последнего полного прогона находятся в `TEST_REPORT.md`.

### Состав проекта

- `report.py` — программа;
- `tests/` — автоматические тесты;
- `DECISIONS.md` — принятые решения и последствия допущений;
- `ACCOUNTANT_NOTE.md` — записка бухгалтеру;
- `TEST_REPORT.md` — результаты детерминированной и генеративной проверки;
- `report/` — пример отчёта на 10.11.2026;
